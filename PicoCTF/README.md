## 📋 Executive Summary
PicoCTF is a premier competitive cybersecurity capture-the-flag platform hosted by Carnegie Mellon University. This directory serves as a centralized archive for challenge solutions, organizing problems across standard competitive domains.

---

## 🗂️ Challenge Categories & Standard Methodologies

### 1. General Skills
* Command-line mastery, piping, grep filtering, octal/hex conversions, bash scripting, and environment variable analysis.

### 2. Web Exploitation
* Cookie tampering, SQL injection, Cross-Site Scripting (XSS), Local File Inclusion (LFI), CSRF, and GraphQL introspection.

### 3. Cryptography
* Classical ciphers (Caesar, Vigenère, Substitution), RSA factorization (Wiener's attack, Fermat's factorization), elliptic curves, and padding oracle attacks.

### 4. Forensics
* Steganography (zsteg, steghide, exiftool), packet capture inspection with Wireshark/tshark, memory analysis with Volatility, and disk image analysis.

### 5. Reverse Engineering
* Static and dynamic analysis using Ghidra, IDA Free, GDB with GEF/PEDA, Radare2, and string extraction from ELF/PE executables.

### 6. Binary Exploitation (Pwn)
* Buffer overflows, ret2win, return-oriented programming (ROP), format string bugs, shellcoding, and ASLR/NX/Canary bypasses using `pwntools`.
